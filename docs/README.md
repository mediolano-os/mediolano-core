# Mediolano Core — Documentation

**Mediolano** is the public-goods intellectual-property tokenization substrate of the Integrity
Web: a permissionless, zero-fee, immutable, interoperable, multichain protocol for tokenizing,
protecting, licensing, and composing intellectual property — Berne-aligned and open to all
intelligences, from human to AI.

The **[Integrity Web Axioms](architecture/00-axioms.md) are the governing authority** of this
architecture. Every document derives from them; where any document conflicts with an axiom, the
axiom wins.
